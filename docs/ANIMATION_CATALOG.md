## #80 TinyBuddy Signature Finale — sequence

| t (ms) | Phase | What happens | Easing / technique |
|---|---|---|---|
| 0 | settle | gaze returns to the viewer | InOutQuad |
| 260 | double blink | normal blink, then a quicker flutter; the face nods 1 px with each | close InQuad, open OutCubic |
| 820 | look left | tiny counter-move right (anticipation), fast saccade with overshoot, curious lid lift, 'reading' micro-adjust | OutBack saccade |
| 1500 | look right | long crossing saccade carrying a half blink (eyes blink on big gaze shifts) | InOutCubic |
| 2050 | centre | back to eye contact | OutQuart |
| 2200 | wind-up | squint to 72 % of resting openness, squash, dip 2 px, mouth purses | InOutQuad (anticipation) |
| 2420 | POP! | eyes fly open and grow (110 %/118 %), pupils dilate, catch-lights flare, open smile, blush; 2 hearts + sparkles start | OutBackBig overshoot, stretch |
| 2700 | celebrate x2 | eyes become `^ ^` arches, laughing mouth with tongue, two bounces with crouch / stretch / land squash | OutCubic up, InQuad down, OutElastic settle |
| 3600 | warm smile | smiling eyes with sparkly pupils | InOutQuad |
| 3950 | lean in | face slides 2 px toward the wink side | InOutQuad |
| 4170 | wink + ting | lid snaps shut, then the closed line bends into `^`; cheeky tongue; a sparkle 'ting!' at the corner; tiny hop | OutQuad then InOutQuad |
| 4850 | unwink | `^` flattens to a line, then the eye opens | InQuad / OutCubic |
| 5000 | recover | every channel eases back to the captured idle pose; blush fades | InOutQuad / InOutSine |
| 5500 | soft blink | one last blink closes the show | |
| 5800 | idle | hands back to idle behaviour (blinks deferred 0.7 s) | |

Per-play variation: mirrored choreography (look right first, wink with the other eye) 50 %, tempo x0.96-1.05, effect position jitter (seeded).
Works on all six candidates because keys can be relative (`MUL`/`ADD`/`BASE`), e.g. the wind-up squint is 72 % of *your* resting openness.
